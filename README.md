# Stavan Jha — Python Portfolio

A responsive personal portfolio built entirely in Python with Streamlit. Styling is embedded inside `app.py`; there are no separate HTML, CSS, or JavaScript source files.

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. Streamlit will open the portfolio in your browser.

## Personal details
The project copy and achievements are based on the supplied resume. Replace the files in `assets/` if you want to update your photo or resume. Verify all external links and details before publishing publicly.

## Deployment
You can deploy this folder on Streamlit Community Cloud by connecting a GitHub repository containing `app.py`, `requirements.txt`, and `assets/`.
